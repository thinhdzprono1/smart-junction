# Module 01 — Python và tổ chức repo

Tuần 1 · Mốc 1. Tạo một repo chạy được và xác định bài toán đếm xe trước khi bắt đầu xử lý video.

## Chạy module

Chạy từ thư mục gốc của repo trong CMD.

```cmd
.\.venv\Scripts\python.exe -m src.smartjunction.module_01.run
```

`run.py` là điểm chạy của module. Khi triển khai, thêm các file `.py` theo từng chức năng vào thư mục này và gọi hàm cần chạy từ `main()`.
