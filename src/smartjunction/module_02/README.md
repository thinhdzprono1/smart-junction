# Module 02 — Vector, ma trận và gradient

Tuần 2 · Mốc 1. Dùng toán để xác định hướng qua vạch và đặt đường cơ sở trên clip mẫu. Kiến thức gradient được dùng lại ở M4.

## Chạy module

Chạy từ thư mục gốc của repo trong CMD.

```cmd
.\.venv\Scripts\python.exe -m src.smartjunction.module_02.run
```

`run.py` là điểm chạy của module. Khi triển khai, thêm các file `.py` theo từng chức năng vào thư mục này và gọi hàm cần chạy từ `main()`.

## Mốc hoàn thành

Mốc 1 dùng quy tắc vạch và kết quả pilot. Bài gradient được kiểm tra khi làm hồi quy ở tuần 4.
