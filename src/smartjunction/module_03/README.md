# Module 03 — Dữ liệu và thống kê

Tuần 3 · Chuẩn bị Mốc 2. Cố định cách ghi và đánh giá dữ liệu trước khi tinh chỉnh mô hình.

## Chạy module

Chạy từ thư mục gốc của repo trong CMD.

```cmd
.\.venv\Scripts\python.exe -m src.smartjunction.module_03.run
```

`run.py` là điểm chạy của module. Khi triển khai, thêm các file `.py` theo từng chức năng vào thư mục này và gọi hàm cần chạy từ `main()`.
