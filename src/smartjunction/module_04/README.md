# Module 04 — Hồi quy và mô phỏng thử

Tuần 4-5 · Mốc 2. Xây hai đường cơ sở song song. Phần mô phỏng thực tế hóa tiếp ở tuần 10-13.

## Chạy module

Chạy từ thư mục gốc của repo trong CMD.

```cmd
.\.venv\Scripts\python.exe -m src.smartjunction.module_04.run
```

`run.py` là điểm chạy của module. Khi triển khai, thêm các file `.py` theo từng chức năng vào thư mục này và gọi hàm cần chạy từ `main()`.

## Mốc hoàn thành

Mốc 2 bàn giao baseline dự báo và mô phỏng thử. Kết quả so phương án đèn chỉ đóng ở Mốc 4.
