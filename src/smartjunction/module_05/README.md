# Module 05 — Deep Learning nền tảng

Tuần 6 · Chuẩn bị Mốc 3. Luyện pipeline PyTorch nhỏ và kiểm tra đầu vào trước khi gắn với video.

## Chạy module

Chạy từ thư mục gốc của repo trong CMD.

```cmd
.\.venv\Scripts\python.exe -m src.smartjunction.module_05.run
```

`run.py` là điểm chạy của module. Khi triển khai, thêm các file `.py` theo từng chức năng vào thư mục này và gọi hàm cần chạy từ `main()`.

## Mốc hoàn thành
