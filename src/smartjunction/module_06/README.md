# Module 06 — CNN, tracker và triển khai thử

Tuần 7-8 · Chuẩn bị Mốc 3. Nối detection với tracking và đưa quy tắc đếm qua vạch vào kiểm thử.

## Chạy module

Chạy từ thư mục gốc của repo trong CMD.

```cmd
.\.venv\Scripts\python.exe -m src.smartjunction.module_06.run
```

`run.py` là điểm chạy của module. Khi triển khai, thêm các file `.py` theo từng chức năng vào thư mục này và gọi hàm cần chạy từ `main()`.
