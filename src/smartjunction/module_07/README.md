# Module 07 — Nghiệm thu đếm xe

Tuần 8-9 · Mốc 3. Chốt đầu ra video → số đếm → dashboard, trên tập giữ riêng được đối chiếu bằng đếm tay.

## Chạy module

Chạy từ thư mục gốc của repo trong CMD.

```cmd
.\.venv\Scripts\python.exe -m src.smartjunction.module_07.run
```

`run.py` là điểm chạy của module. Khi triển khai, thêm các file `.py` theo từng chức năng vào thư mục này và gọi hàm cần chạy từ `main()`.
