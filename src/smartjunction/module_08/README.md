# Module 08 — NLP và quyết định về dự báo

Tuần 14-16 · Mốc 5. Học NLP theo AIO và kiểm tra tính khả thi của dự báo. Nhánh cảnh báo là phần mở rộng.

## Chạy module

Chạy từ thư mục gốc của repo trong CMD.

```cmd
.\.venv\Scripts\python.exe -m src.smartjunction.module_08.run
```

`run.py` là điểm chạy của module. Khi triển khai, thêm các file `.py` theo từng chức năng vào thư mục này và gọi hàm cần chạy từ `main()`.

## Mốc hoàn thành

Các mục 8.3-8.4 là công việc dự án ở Mốc 5. Nhánh NLP cảnh báo có thể dừng sau bài luyện nếu nguồn chưa phù hợp.
