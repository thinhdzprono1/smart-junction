# Module 09 — Mô hình sinh và đóng gói

Tuần 17-18 · Chuẩn bị Mốc 6. Dùng lỗi quan sát được để chọn thử nghiệm tăng độ bền. Đóng gói bản demo đã kiểm tra.

## Chạy module

Chạy từ thư mục gốc của repo trong CMD.

```cmd
.\.venv\Scripts\python.exe -m src.smartjunction.module_09.run
```

`run.py` là điểm chạy của module. Khi triển khai, thêm các file `.py` theo từng chức năng vào thư mục này và gọi hàm cần chạy từ `main()`.

## Mốc hoàn thành

Bản đóng gói chạy bằng dữ liệu mẫu đủ quyền dùng. Kết quả cải thiện Vision phải truy được đến lỗi và phép đo.
